# 이거사면인생바뀜 · 전편 상품 모음

유튜브 쇼핑 쇼츠 채널 **이거사면인생바뀜**(https://www.youtube.com/@lifechange_pick)의
EP.01~EP.06에 소개한 상품 18개를 한 페이지에서 다시 찾아볼 수 있게 모은 안내 페이지입니다.

- 라이브: https://peem931029-cell.github.io/lifechange-pick/
- 구성: `index.html` (단일 파일, CSS·JS 포함) + `assets/` (상품 썸네일 240×240 webp)
- 모바일(유튜브·인스타·스레드 인앱 브라우저) 우선 설계, 검색·테마 필터 지원

## 고지

이 페이지의 링크는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
표시된 가격과 상품평 수는 각 영상 게시일 기준입니다.

## 갱신

새 화차가 올라오면 `index.html`의 `#list` 맨 앞에 새 카드를 추가하고
`assets/epNN-1..3.webp` 썸네일을 넣은 뒤 히어로의 편수·상품 수와 푸터를 갱신합니다.
